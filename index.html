Controls the game: reveal answers, strikes, scores, Fast Money, and the game editor. It shows a 4-letter room code.

📺 Board / projector

The big screen everyone watches. Type the room code from the host screen.

Tip: on the board computer, click once anywhere to enable sound, then press F for fullscreen. Both computers need internet. If the school network blocks the connection, open the board in a second window on the host computer instead (host page → “Open board in this computer”) and drag that window to the projector.
